# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/cagrikacmaz/package-name-risk/security/advisories/new). Do not open a public issue for a vulnerability that has not been coordinated.

Include the affected version, impact, reproduction steps, and any suggested mitigation. You should receive an acknowledgment within seven days. Disclosure timing will be coordinated after the report is understood and a fix is available.

## Scope

Security issues in the library, CLI, build output, and release process are in scope. Disagreements about a similarity score or a missing heuristic are normally correctness issues rather than vulnerabilities.

Only the latest released major version receives security fixes.
