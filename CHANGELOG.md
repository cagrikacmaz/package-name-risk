# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-05

### Added

- Programmatic package-name risk analysis with explainable signals and deterministic scoring.
- Detection for edit distance, transposition, insertion, deletion, repetition, separators, scopes, selected Unicode homoglyphs, and generic attachments.
- Popular-package weighting and deterministic candidate ranking.
- Text and JSON command-line interfaces with CI-oriented exit codes.
- TypeScript declarations and ESM/CommonJS library builds.
